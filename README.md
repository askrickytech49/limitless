# Limitless Schools responsive redesign

This revision fixes the horizontal overflow problem on desktop and mobile and replaces the placeholder visual treatment with the supplied Limitless Schools photographs.

Brand colours: #1A3B60, #8CBAE6, #E2A42D
Typography: Della Respira throughout.

Pages: Home, About, Admissions, Classes, Gallery, Contact.

Responsive fixes include global box sizing, overflow protection, minmax grid columns, mobile one column layouts, responsive navigation, responsive image crops, and mobile gallery handling.

The supplied photographs are stored in assets/images/.
